# Расширения

Расширение — модуль, который добавляет в редактор что-то одно: формат экспорта, хранилище, панель, команду, календарь. Все встроенные функции такого рода написаны как расширения, поэтому API проверен собственным кодом.

Источник истины по типам — `packages/app/src/ext/api.ts`. Реестры и запуск — `packages/app/src/ext/host.ts`.

## Как устроено

```ts
export const myExtension: Extension = {
  id: 'google.drive',          // уникальный, стабильный; он же пространство имён для данных
  name: 'Google Drive',
  activate(ctx) {
    ctx.storage.register(driveProvider);
    ctx.commands.register({ id: 'google.drive.signIn', title: 'Войти в Google', run: signIn });
  },
};
```

Расширения компилируются вместе с приложением. Чтобы подключить новое, добавьте его в массив в `packages/app/src/ext/builtin/index.ts`. Загрузки сторонних расширений во время работы в v1.0 нет.

`activate` вызывается один раз при старте. Ошибка в одном расширении не мешает остальным: она пишется в консоль.

## Точки расширения

| Реестр | Что регистрируется | Где видно в интерфейсе |
|---|---|---|
| `ctx.commands` | `Command` — действие с необязательной горячей клавишей | Кнопка на панели инструментов (`toolbar: true`) и/или сочетание клавиш |
| `ctx.exporters` | `Exporter` — документ → строка или `Blob` | Меню «Экспорт…» |
| `ctx.importers` | `Importer` — текст файла → `Doc` | Меню «Импорт…» (скрыто, пока импортёров нет) |
| `ctx.panels` | `Panel` — React-содержимое боковой панели | Кнопка-переключатель справа на панели инструментов |
| `ctx.storage` | `StorageProvider` — место хранения файлов | «Открыть» и «Сохранить»; первый зарегистрированный — по умолчанию |
| `ctx.reminderSinks` | `ReminderSink` — внешний календарь для напоминаний | Состояние и кнопка подключения в панели «Напоминания»; синхронизация — сама после изменения напоминаний |

Каждый `register` возвращает функцию отмены регистрации. Повторная регистрация того же `id` — ошибка.

## Доступ к редактору: `ctx.editor`

- `doc`, `sheet`, `selection`, `viewRoots`, `fileName` — текущее состояние активного файла. Это геттеры: читайте их в момент использования, не сохраняйте в переменные надолго.
- `select(id)` — выбрать тему: переключает лист, выходит из drill-down и разворачивает свёрнутые ветки, если нужно.
- `apply(ops, label)` — **единственный способ изменить документ**. Один вызов — один шаг undo. Возвращает `false`, если операции отклонены.
- `openDoc(doc, name)` — открыть документ в новой вкладке.
- `subscribe(listener)` — уведомление о любом изменении.

## Правила

1. Документ меняется только через `editor.apply`. Присваивать поля `doc` напрямую нельзя: сломается undo и автосохранение.
2. Свои данные расширение хранит в поле `ext` документа, листа, узла или связи под ключом, равным своему `id`:
   `{ t: 'patchNode', id, patch: { ext: { ...node.ext, 'google.calendar': { eventId } } } }`.
   Чужие ключи в `ext` не трогать; при записи сохранять их, как в примере.
3. Экспортёр и импортёр — чистые функции от входа: без обращения к DOM и к `ctx.editor`. Раскладку экспортёр берёт из `input.layout()`, а не считает сам; растровую картинку из SVG — из `input.rasterize(svg)` (её рисует редактор). Тогда они тестируются в Node (см. `packages/app/test/export.test.ts`) и пригодны для CLI.
4. Экспортёр выгружает то, что передано в `rootIds` (видимые сейчас карты), а не весь документ. Если формат не умеет что-то хранить, это перечисляется в комментарии к функции экспорта.
5. Импортёр возвращает документ, проходящий `validate`; иначе пользователь увидит ошибку, и файл не откроется.
6. Провайдер хранилища с `canAutosave: true` обязан сохранять без участия пользователя и возвращать новую `version` после записи; `version(ref)` должна меняться при любом внешнем изменении файла — на этом построено обнаружение конфликтов.
7. Секреты (токены OAuth) не пишутся в документ и в `ext`. Токены Google живут только в памяти (`ext/google/auth.ts`); если расширению понадобится хранить своё, место — хранилище браузера, ключ — `id` расширения.
8. Команда не должна занимать клавиши редактора (Tab, Enter, F2, F6, Del, стрелки, Ctrl+Z/Y/S/O). Формат клавиши: `Ctrl+Alt+Shift+K`, модификаторы именно в таком порядке.

## Встроенные расширения — образцы

| Файл | Что показывает |
|---|---|
| `ext/builtin/index.ts` (`builtin.local-files`) | Регистрация хранилища |
| `ext/builtin/exportMarkdown.ts` | Простой экспортёр |
| `ext/builtin/exportFreeMind.ts` | Экспорт с упрощением структуры и перечнем потерь |
| `ext/builtin/exportSvg.ts` | Экспорт-картинка из раскладки `input.layout()` |
| `ext/builtin/exportWord.ts` | Двоичный формат (`.docx` — ZIP с XML, `ext/builtin/zip.ts`), экспортёр возвращает `Blob` |
| `ext/builtin/exportPdf.ts` | PDF из SVG через `input.rasterize`; сборка файла PDF — чистая функция |
| `ext/builtin/attributes.tsx` | Панель с формой, создающая определения в документе (`putAttrDef`) |
| `ext/builtin/prompt.tsx` | Панель, которая читает живое значение поля при нажатии кнопки, а не ждёт его потери фокуса |
| `ext/builtin/reminders.tsx` | Панель со списком, ведущим к темам через `editor.select` |
| `ext/builtin/notes.tsx` | Панель, читающая выделение и меняющая документ через `apply` |

## Как писать запланированные расширения

**Google Drive (`google.drive`).** Сделано: `ext/google/drive.ts`, подробности в `docs/GOOGLE.md`. `handle` — `{ id }` файла, `version` — поле `version` Drive, `canAutosave: true`, `pickOpen` — Google Picker. Отдельной команды входа нет: вход открывается сам при «Открыть» и «Сохранить».

**Google Calendar (`google.calendar`).** Сделано: `ext/google/calendar.ts`, подробности в `docs/GOOGLE.md`. `ReminderSink.sync(doc)` приводит календарь в соответствие со всеми напоминаниями карты; вход общий с Диском (`ext/google/auth.ts`).

**Google Docs (`google.docs`).** `Exporter`, возвращающий `Blob` не подходит: документ создаётся в облаке. Делается командой: взять текст из `exportMarkdown`-подобной функции, создать документ через Docs API, записать ссылку в `link` узла через `apply`.

**PDF.** Сделано: `ext/builtin/exportPdf.ts` — SVG-картинка, растрированная редактором (вдвое крупнее, JPEG), на одной странице размером с карту. Текст в PDF не выделяется: для векторного PDF с кириллицей нужен встроенный шрифт.

**Word.** `Exporter` с `Blob` `.docx`: структура заголовками, как в Markdown. Библиотека — с лицензией MIT/Apache.

**Импорт FreeMind.** `Importer` с `extensions: ['.mm']`: разобрать XML через `DOMParser`, построить `Doc` функциями `createDoc`/`createNode` и операциями `insertSubtree`.

## Чего в API пока нет

- Собственные типы атрибутов и отрисовка значков на узле.
- Пункты контекстного меню.
- Настройки расширений с интерфейсом.

Добавлять их по мере появления первого расширения, которому они нужны, тем же способом: тип в `api.ts`, реестр в `host.ts`, раздел в этом документе.
