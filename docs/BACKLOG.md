# Бэклог

Пометки сложности: **[F]** — архитектурно важное, делать на Fable 5.2 (доступ до 2026-11-16); **[O]** — по силам Opus 5.5 по готовой спецификации; **[S]** — рутинное, подойдёт Sonnet/Haiku.

Правило: задача закрыта, когда выполнены её критерии, проходят `npm test` и `npm run typecheck`, а пункт отмечен здесь.

## Этап 1. Редактор на Windows — текущий

- [ ] [F] `packages/app`: каркас Vite + React, хранилище состояния поверх `History`.
- [ ] [F] Раскладка: интерфейс `layout()`, структура «логическая схема вправо», кэш по поддеревьям. Критерий: 5000 узлов раскладываются быстрее 50 мс, правка одного узла — быстрее 5 мс.
- [ ] [F] Рендер на Canvas через `DrawSurface`, панорамирование, масштаб, отсечение. Критерий: 60 кадров/с на 5000 узлов.
- [ ] [F] Hit-test, выделение, редактирование текста поверх Canvas.
- [ ] [F] Клавиатура как в XMind 8: Tab/Insert — дочерний, Enter — соседний, F2 — правка, Del, стрелки, Ctrl+Z/Y, «+»/«−» свёртка, F6 — drill-down, Shift+F6 — вверх.
- [ ] [F] Drill-down: `focusPath`, навигационная цепочка.
- [ ] [F] Перетаскивание веток (смена родителя и порядка), несколько карт на листе.
- [ ] [F] Спецификация `StorageProvider` + LocalFs (File System Access API), открыть/сохранить, автосохранение, несколько открытых файлов.
- [ ] [O] Структуры: карта в обе стороны, дерево, оргсхема.
- [ ] [O] Листы: вкладки, добавить/переименовать/удалить; команды «вынести на лист» и «влить лист».
- [ ] [O] Копировать/вставить через `Fragment`; перенос ветки в другой открытый файл.
