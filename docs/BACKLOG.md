- [x] [F] Перетаскивание ветки на другой узел; новая карта на листе двойным щелчком по пустому месту; перетаскивание корня.

Осталось:

- [x] [F] Черновики: несохранённые документы копируются в `localStorage` (`oc-draft:<doc.id>`) и открываются вкладками после перезагрузки страницы (`App.tsx`: `restoreDrafts`, `writeDrafts`).
- [ ] [O] Черновик восстанавливается без привязки к файлу. Хранить ссылку на файл (handle в IndexedDB) и предлагать «сохранить в прежний файл»; для больших карт перенести черновики из `localStorage` в IndexedDB.
- [ ] [S] Если File System Access API есть, но чтение запрещено платформой (так во встроенном браузере Claude), открывать файл через `downloadFs`.

- [ ] [S] Проверить вручную в Edge/Chrome: «Сохранить», «Открыть», автосохранение, предупреждение о внешнем изменении файла (диалог выбора файла нельзя автоматизировать).
- [x] [F] Замер на 5000 узлах в браузере: раскладка 6 мс (первая — 120 мс из-за измерения текста), кадр 3–7 мс на любом масштабе, hit-test < 0,1 мс. Кэш по поддеревьям и пространственный индекс не нужны. При отдалении текст мельче 3,5 px и переключатели не рисуются (`view/render.ts`).

- [ ] [O] Множественное выделение (Ctrl/Shift+щелчок, рамка) и групповые операции.
- [ ] [O] Структуры: дерево, оргсхема; выбор структуры листа и ветки в UI.
