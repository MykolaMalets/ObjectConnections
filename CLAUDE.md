# ObjectConnections

Редактор интеллект-карт в духе XMind 8 для Windows и Android (личное использование, v1.0).
Рабочее название — ObjectConnections; итоговое имя не выбрано.

## С чего начинать любой сессии

1. Прочитать `docs/BACKLOG.md` — там текущий этап, очередь задач и пометки, какой модели задача по силам.
2. Перед изменением ядра прочитать `docs/FORMAT.md` (модель данных и операции) и `docs/ARCHITECTURE.md`.
3. Экспорт, импорт, хранилища, панели, календарь пишутся как расширения — перед такой задачей прочитать `docs/EXTENSIONS.md`.
4. Решения, которые нельзя менять без согласия пользователя, — в `docs/DECISIONS.md`.
5. После завершения задачи: отметить её в `docs/BACKLOG.md`, прогнать `npm test` и `npm run typecheck`.

## Структура

- `packages/core` — модель документа, операции, история, фрагменты. Без DOM, без зависимостей.
- `packages/app` — веб-редактор: `view/` (раскладка, рендер на Canvas, жесты), `state/` (сессии, все действия пользователя, файлы), `storage/` (провайдеры хранилищ), `ext/` (API расширений, хост и встроенные расширения).
- `packages/cli` — CLI `oc` для агентов и скриптов (`npm run oc -- help`). MCP-сервера ещё нет.
- `.claude/skills/ocmap` — скилл, по которому Claude работает с картами через `oc`. При изменении команд CLI обновлять и его.
- `docs/` — архитектура, формат, решения, бэклог; `docs/GOOGLE.md` — вход в Google и Диск.

## Команды

- `npm test` — тесты ядра (встроенный `node --test`, TypeScript исполняется Node 24 напрямую).
- `npm run typecheck` — проверка типов (у каждого пакета свой `tsconfig.json`; ядро собирается без DOM).
- `npm run build`, затем `npm run preview -w @oc/app` — собранное приложение на http://localhost:4173 (с service worker; так проверяется установка и офлайн).
- `node scripts/make-icons.mjs` — пересоздать значки приложения в `packages/app/public/icons`.
- `npm run dev` — редактор на http://localhost:5173. В dev-режиме рабочее пространство доступно как `window.__ws` — удобно проверять состояние из консоли.

## Правила кода

- Любое изменение документа идёт только через `Op` и `History.apply` (`packages/core/src/ops.ts`). Прямо менять поля документа вне `ops.ts` нельзя: ломается undo и агентный API.
- У каждой новой операции обязаны быть: обратная операция, проверка предусловий до мутации, тест «apply → undo даёт исходный документ».
- В приложении `History.apply` вызывают только действия из `packages/app/src/state/store.ts`; компоненты вызывают действия.
- Раскладка (`view/layout.ts`) — чистая функция без DOM; у каждой новой структуры должен быть тест на отсутствие наложений.
- `packages/core` не импортирует ничего из DOM, React, Node API.
- В `packages/core` только стираемый синтаксис TypeScript (без `enum`, `namespace`, parameter properties); импорты с расширением `.ts`.
- Идентификаторы и комментарии в коде — на английском; документация в `docs/` — на русском.
- Формат файла меняется только с повышением `version` и миграцией в `packages/core/src/migrate.ts` (создать при первой необходимости).
- Коммиты и push — только по просьбе пользователя.

## Окружение

Windows 10, Node 24, npm 11, JDK 21. Rust и Android SDK не установлены — см. решение D3 в `docs/DECISIONS.md`.
